# SmallWorks

Small projects created from small ideas.

用于收集和实现小想法的项目仓库。

## 协作方式

1. 用 Issue 记录要解决的问题或要实现的想法。
2. 从最新的 `main` 创建分支，在分支上完成修改。
3. 检查修改并运行与改动相关的验证，再提交和推送。
4. 创建 Pull Request（PR），说明修改原因、内容和验证结果。
5. 检查差异、处理审查意见后合并，再更新本地 `main`。

## 使用 Codex

在 Codex 中打开本仓库目录，可以直接提出具体任务，例如：

- “介绍当前仓库的内容和 Git 状态。”
- “根据 Issue 链接实现修改，先在新分支上工作。”
- “检查当前差异，说明修改内容和验证结果。”
- “提交并推送当前修改，创建一个草稿 PR。”
- “阅读这个 PR 的审查意见，修复问题并验证。”

提交（commit）把修改记录到本地历史；推送（push）把提交同步到 GitHub；
PR 则把分支上的修改整理成可以审查和合并的请求。
